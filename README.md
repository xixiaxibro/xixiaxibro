## Research Perspective

I treat AI agents as **networked, compositional software systems**, not isolated language models. The central question is how individually benign components can interact through information flow, memory, tools, protocols, registries, packages, and external services to create emergent security risks.

**Research direction:** Measuring and securing networked AI/Agent infrastructure.
